# Download configuratori Winnerdoor

Archivio pubblico dei soli pacchetti di distribuzione approvati. I sorgenti e la gestione rimangono privati.

Il Centro download Winnerdoor è https://www.winnerdoor.it/test-page.

Nessun account GitHub o installazione di Git è richiesto agli utilizzatori per i download pubblici.

La preparazione iniziale contiene un indice senza rilascio stabile e materiali sintetici di collaudo separati. COLLAUDO-001 non è un modello del catalogo ufficiale e non viene proposto nel canale stabile.

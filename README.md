# Download configuratori Winnerdoor

Archivio pubblico dei soli pacchetti di distribuzione approvati. I sorgenti e la gestione rimangono privati.

## Winnerdoor Privati 1.0.4

Rilascio approvato del 5 novembre 2026, per Windows 10/11 x64.

- [Installer Windows 1.0.4](https://github.com/Mixall-Group/winnerdoor-configuratori-download/releases/download/winnerdoor-privati-v1.0.4/Winnerdoor-Setup-1.0.4.exe)
- [ZIP portabile 1.0.4](https://github.com/Mixall-Group/winnerdoor-configuratori-download/releases/download/winnerdoor-privati-v1.0.4/Winnerdoor-Privati-1.0.4-portabile.zip)
- [Guida e impronte della consegna](https://github.com/Mixall-Group/winnerdoor-configuratori-download/releases/tag/winnerdoor-privati-v1.0.4)
- [Centro download Winnerdoor](https://www.winnerdoor.it/test-page)

L’installer chiede la cartella di installazione e crea i collegamenti con la W. In aggiornamento, confermare la cartella della versione già installata. Per il portabile estrarre tutta la cartella prima di avviare Winnerdoor.exe. Non servono Rust, Git o un account GitHub.

Il catalogo ufficiale contiene 178 schede, senza modello fittizio. Gli aggiornamenti del programma e del catalogo usano indici distinti. I cataloghi verificati entrano in uso al prossimo avvio. Il programma si aggiorna mediante l’installer approvato avviato dall’utilizzatore. Le immagini remote richiedono Internet a ogni nuova sessione.

WinnerLite privati e le versioni rivenditori non sono ancora distribuiti. I materiali sintetici di collaudo rimangono separati dagli indici ordinari e non sono modelli ufficiali.
